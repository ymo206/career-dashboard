## Project Overview

Career Dashboard is an expanded version of my Internship
Application Tracker. The original project allowed users
to add applications, update their statuses, and keep
track of their progress.

For Artifact 5, I want to turn it into a more complete
application that students can use throughout their job
and internship search.

The goal is to build something larger than my previous
projects while learning how to manage an application
with multiple connected features.

## Main Features

### 1. Application Management

Users will be able to:

- Add and edit internship applications
- Delete applications
- Save company names and job titles
- Add application dates and deadlines
- Attach job posting links
- Add notes to individual applications
- Search and filter applications

### 2. Application Board

Create a Kanban board that organizes applications
by their current status.

Planned statuses:

- Saved
- Applied
- Interviewing
- Offer
- Rejected

Users should be able to move applications between
columns and see their progress.

### 3. Dashboard and Analytics

Create a dashboard that displays:

- Total applications
- Applications by status
- Interview count
- Offer count
- Application trends over time
- Charts showing application progress

### 4. Interview Management

Add a section where users can:

- Schedule interviews
- Record interview dates and times
- Add interview notes
- Track upcoming interviews
- Mark interviews as completed

### 5. Resume Management

Build a section for organizing resumes.

Possible features:

- Upload resume files
- Store resume names
- Connect resumes to applications
- View saved resume information

### 6. User Accounts and Database

Explore adding authentication and database storage.

Possible features:

- User registration
- User login
- Separate application data for each user
- Data saved across devices

This is a stretch goal. I will focus on having a
working application before adding more advanced
account features.
